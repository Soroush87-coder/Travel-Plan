# مولد برنامه سفر چندمقصده (Travel Itinerary Generator)

یک اپلیکیشن Next.js که فرم سفر را می‌گیرد، با هوش مصنوعی Claude برنامهٔ روزبه‌روز می‌سازد و خروجی PDF تمیز می‌دهد.

> ⚠️ نکتهٔ مهم: نسخه‌ای که داخل Claude.ai کار می‌کرد، کلید API را خودِ Anthropic تزریق می‌کرد. روی سرور خودت این اتفاق نمی‌افتد. به همین خاطر این پروژه یک بک‌اند کوچک دارد که کلید را **روی سرور** نگه می‌دارد و هیچ‌وقت در مرورگر کاربر دیده نمی‌شود. پس قبل از هر چیز به یک کلید API نیاز داری.

---

## ۰) چیزی که لازم داری
- یک کلید Anthropic API از https://console.anthropic.com (بخش API Keys) — باید کمی اعتبار/Credit داشته باشد.
- یکی از این دو مسیر برای دیپلوی: **Coolify روی VPS خودت** یا **Vercel**.

---

## مسیر A — دیپلوی روی سرور خودت با Coolify (همان داشبورد گرافیکی‌ات)

۱. فایل zip را باز کن. حالا یک پوشهٔ پروژه داری.

۲. کد را روی GitHub بگذار (بدون نیاز به ترمینال):
   - وارد https://github.com شو → New repository → یک نام بده → Create.
   - در صفحهٔ ریپو روی «uploading an existing file» بزن و **محتوای داخل پوشهٔ پروژه** را (نه خود پوشه را) drag & drop کن → Commit.

۳. در Coolify:
   - **+ New** → **Resource** → **Public/Private Repository** را انتخاب کن و ریپوی GitHub را وصل کن.
   - Coolify خودش Next.js را تشخیص می‌دهد (Build Pack = Nixpacks). دستی کاری لازم نیست.
   - برو به تب **Environment Variables** و این‌ها را اضافه کن:
     - `ANTHROPIC_API_KEY` = کلید خودت
     - (اختیاری) `ANTHROPIC_MODEL` = `claude-sonnet-4-6`  (برای ارزان‌تر و سریع‌تر: `claude-haiku-4-5`)
   - **Deploy** را بزن.

۴. بعد از سبز شدن دیپلوی، در تب **Domains** دامنه یا زیردامنه‌ات را وصل کن. تمام.

> اگر Coolify پورت پرسید: این اپ به‌صورت خودکار به متغیر `PORT` گوش می‌دهد، پس معمولاً نیازی به تنظیم دستی نیست.

---

## مسیر B — دیپلوی روی Vercel (ساده‌ترین حالت)

۱. کد را مثل مرحلهٔ ۲ بالا روی GitHub بگذار.
۲. وارد https://vercel.com شو → **Add New → Project** → ریپو را Import کن.
۳. در همان صفحه، بخش **Environment Variables**:
   - `ANTHROPIC_API_KEY` = کلید خودت
   - (اختیاری) `ANTHROPIC_MODEL` = `claude-sonnet-4-6`
۴. **Deploy** را بزن. لینک نهایی را تحویل می‌گیری.

---

## اجرای محلی روی کامپیوتر خودت (اختیاری، برای تست)

نیاز به Node.js نسخهٔ ۱۸ به بالا.

```bash
npm install
cp .env.example .env.local   # داخل .env.local کلیدت را بگذار
npm run dev
```

سپس http://localhost:3000 را باز کن.

برای حالت پروداکشن:
```bash
npm run build
npm run start
```

## نکات

- **کلید را هیچ‌وقت داخل کد نگذار.** فقط از Environment Variables استفاده کن (همان جاهایی که بالا گفته شد).
- **هزینه:** هر بار «Generate» برای هر مقصد یک درخواست کوچک به Claude می‌زند. مدل `claude-haiku-4-5` ارزان‌ترین گزینه است.
- اگر برنامه ساخته شد ولی متن‌ها عمومی بودند (مثل «Visit the principal landmarks»)، یعنی به API وصل نشده — کلید یا اعتبار را چک کن و دوباره Regenerate بزن. اپ طوری ساخته شده که حتی بدون AI هم یک برنامهٔ استاندارد بسازد و خراب نشود.
- **PDF:** دکمهٔ «Save as PDF» پنجرهٔ چاپ مرورگر را باز می‌کند؛ آنجا مقصد را روی «Save as PDF» بگذار. این روش متنِ قابل‌انتخاب می‌دهد که برای مدارک ویزا بهتر است.

## تغییر مدل
مدل پیش‌فرض `claude-sonnet-4-6` است. برای عوض‌کردن، فقط متغیر `ANTHROPIC_MODEL` را تغییر بده و دوباره دیپلوی کن.
